# brawijaya-mart

Brawijaya Mart is a responsive grocery product catalog website developed using PHP, MySQL, Bootstrap, JavaScript, HTML, and CSS. The website is designed to provide an easy and user-friendly way for customers to browse grocery products, view product details, and place orders through WhatsApp.

The project also includes an admin dashboard for managing the catalog data. Administrators can log in securely and manage product categories and product information, including product names, prices, descriptions, variants, images, and stock. The dashboard provides a simple interface for adding, editing, and deleting data stored in the MySQL database.

## Features

* Responsive product catalog for desktop and mobile devices
* Product listing and product detail pages
* Product categorization
* Product search and sorting
* Product image management
* Product price, variant, and stock management
* Admin login and authentication
* Admin dashboard with product and category management
* Add, edit, and delete product categories
* Add, edit, and delete products
* WhatsApp ordering integration
* MySQL database integration
* Responsive interface using Bootstrap

## Technologies

* PHP
* MySQL
* Bootstrap 5
* JavaScript
* HTML5
* CSS3

## Project Purpose

This project was developed as a web development and database management project to implement a simple digital product catalog for a grocery store. It demonstrates the implementation of CRUD operations, database integration, admin authentication, responsive web design, and integration with WhatsApp for customer orders.

## Deployment

The website is deployed using a free web hosting service and uses MySQL as the database management system.
